# Beadscope v0.5.1 — Install docs and update instructions

A small follow-up to 0.5.0 with no behavior changes. It is the first release published
by the release workflow, with npm provenance, so the package page and the Homebrew
formula now come from the same tag.

## Improvements

- **The README documents every install channel.** Quick install leads with
  `npm install -g beadscope` and `brew install sai-manoj-kumar/beadscope/beadscope`,
  with the update commands. The clone-based install moves to "Install from source", and
  the Docker section now says there is no published image and builds from a clone.
- **The update notice names the right commands.** An installation that cannot update
  itself (npm, Homebrew, a source download or Docker) now tells you to run
  `npm install -g beadscope` or `brew upgrade beadscope`, then `beadscope stop` and
  `beadscope start`.

## Behind the scenes

- Pushing a `vX.Y.Z` tag now publishes to npm, creates the GitHub release and bumps the
  Homebrew tap. See [`docs/releases/README.md`](README.md).
- 0.5.0 was published straight to npm before this workflow existed, so it has no git tag
  or GitHub Release page; its notes are in [`v0.5.0.md`](v0.5.0.md).

## Update

```sh
npm install -g beadscope        # or: brew upgrade beadscope
beadscope stop && beadscope start
```

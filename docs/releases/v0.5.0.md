# Beadscope v0.5.0 — The first Beadscope release

Beadscope is a local web UI for the [beads](https://github.com/gastownhall/beads) (`bd`)
issue tracker. This is the first release under the Beadscope name, forked from
[Bead Me Up, Scotty](https://github.com/brendan-appstart/bead-me-up-scotty) v0.4.0.
Version numbers continue from there. It is a breaking release: the command, environment
variables and config directory are all renamed.

## Breaking changes

- **The package and command are `beadscope`.** Install it from npm or Homebrew and run
  `beadscope start`, `stop`, `status`, `logs` or `run`.
- **Environment variables are `BEADSCOPE_*`** (for example `BEADSCOPE_ALLOWED_HOSTS`).
- **Config lives in `~/.config/beadscope`.** Nothing is migrated from an older install.
- **Browser storage keys and events are `beadscope.*`.** Saved themes and layout widths from
  an older install are not carried over.

## New

- **System theme.** Beadscope now follows your OS light or dark appearance by default.
  The sidebar toggle flips to the opposite of what is showing; pick **System** again in
  Settings to resume following the OS.
- **Launcher prints every reachable URL.** `beadscope start`, `run` and `status` list the
  hostnames from `BEADSCOPE_ALLOWED_HOSTS` next to `localhost`, so a friendly name such as
  `beadscope.local` is one copy-paste away.
- **Start, stop and status commands.** `beadscope start` runs the server in the background
  and remembers it in `~/.config/beadscope/server.json`.

## Fixes

- **Telemetry reports only when you set a token.** Beadscope no longer bundles a PostHog
  token; with none configured it sends nothing.
- **Update checks and repo links point at this repository.**

## Install

**npm** (Node.js 20 or newer):

```sh
npm install -g beadscope
beadscope start
```

**Homebrew** (macOS):

```sh
brew install sai-manoj-kumar/beadscope/beadscope
beadscope start
```

Beadscope needs the beads `bd` CLI for live project data; the Homebrew formula installs it.
Without `bd` it runs with demo data.
